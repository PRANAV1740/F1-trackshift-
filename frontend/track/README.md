# frontend/track

**Status:** implemented (Phase 24).

Interactive track visualization: car and opponent positions, racing line,
braking points, corners, gaps, traffic. Selecting a corner shows braking
deviation, apex speed, exit speed, and estimated time loss sourced from
`backend/racing_line` (problem prompt section 26).

Implemented in `frontend/index.html` (Track Viz tab) and `frontend/app.js`.
